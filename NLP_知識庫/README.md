## 使用方式

1. **想快速建立全貌**:先讀 `00_導論與知識地圖`
2. **想讀一手實料**:從 `01_上課心得`、`02_讀書筆記`、`03_演講逐字稿` 萃取資料開始
3. **想練技巧**:按 `05_技巧大全` 的練習路徑循序進行
4. **想成為教練**:讀 `06_教練應用指南`,參考 `07_技能發展路線`
5. **免費教材**:`04` 資料夾內含 Goodman 執行師課程完整筆記 PDF、《NLP Pocketbook》試讀本、NVI 與 NLP World 兩份美系訓練手冊,可對標付費課綱自行研讀
6. **想追根溯源(美國)**:讀 `08_美系資料萃取`——官方定義原文、兩派體系差異、免費百科與認證手冊、學界證據、商業應用原文
7. **想確認「哪些可信、哪些只是理論」**:讀 `09_詳細檢視報告`——24 項主張逐項分級(A 已證實→E 已被否證)、5 大矛盾點、6 個核心重點
8. **想開始實際教練會談**:讀 `10_教練Agent`——可直接在 Manus 中裝載啟動的 NLP 教練對話系統(含會談腳本、提問庫、倫理約束)

## 萃取原則

- 原文忠實萃取,保留學員與講師的第一手描述
- 每條萃取資訊標注來源
- 技巧檔採用統一模板:原理 → 步驟腳本 → 常見問題 → 練習方法 → 教練應用 → 來源
- 所有萃取內容來自公開網路資源(學員公開心得、公開書評、公開演講逐字稿、公開講義),並在各檔案內標註原始連結
- 本知識庫僅供個人學習使用
