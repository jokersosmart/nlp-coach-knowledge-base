# 08-4 美系商業應用原文譯本:《NLP in Business》

**萃取日期**:2026-08-17 | 來源:David Molden,《Neuro-linguistic Programming (NLP) in Business》,Positive Health 雜誌第 154 期,2009 年 1 月(全文重點譯述)。原文為企業訓練出身的懷疑論者轉為擁護者的第一手論述,是「NLP 商業教練」論述的原始對標文本。

## 一、作者背景

Molden 曾任 Computacenter plc 的培訓發展主管(1992 年起接觸 NLP),2009 年以管理顧問公司 Quadrant 1 創辦人身分撰文。他的轉折來自一個訓練者最常面對的挫敗:「我給學員很好的理論、有趣的練習和個人行動計畫,但**看不到任何行為改變**。」他觀察到連昂貴的商學院領袖課程也無法改變學員回職場後的行為方式——直到 NLP 提供了他欠缺的「改變心理內部狀態」的方法。

## 二、Mercedes 模型:本長文的核心貢獻

原文提出的模型將任何行為分解為三個同時運作的面向:

| 面向 | 英文 | 內容 |
| --- | --- | --- |
| 外在行為 | EB, External Behavior | 可見的行為表現 |
| 內在狀態 | IS, Internal State | 情緒、感受、生理狀態 |
| 內在思考歷程 | IP, Internal Processing | 自我對話、信念價值觀、對可能性的感知 |

原文的關鍵論證:

> 「除非期望的新行為能以相同的內在狀態與思考歷程生成,否則任何理論、模型或程序都不太可能改變行為。想要行為改變,**從狀態開始**,然後再進入思考歷程。」

對照傳統訓練「只給行為」(教人話術、模仿講師)之所以無效,就在於沒有對齊 IS 與 IP。Molden 明言「行為訓練成效差,是因為無用的習慣擋在前面」;高階 NLP 訓練師的做法是「先用 NLP 創造適當的 IP 與 IS,再把新技能轉移到職場」。

## 三、兩個實戰案例

**信心建構**:信心是 IS+IP 的函數。失去信心的瞬間機制是自我對話介入(「我會搞砸」「他們是一群難搞的人」)→ 立即衝擊情緒狀態。解法:先處理狀態(狀態管理技術),再用新的語音與新的詞語建立新技能。這是 NLP 在「快速建立信心」上得分最高的場景。

**時間管理**:Molden 自述「曾花數十萬英鎊企業預算上時間管理課,學員依然掙扎」;而 NLP 引入的 **Time Coding + Time Lines(時間編碼與時間線)** 解釋了失敗原因——個人對時間的感知是回溯到學生時代(甚至更早)的習慣性 IP/IS/EB 產物,因此要先重建時間的心理編碼與心理時間線,才談得上掌控時間運用。原文主張:「時間管理不是技能問題,是感知問題。」

## 四、對台灣 NLP 教練市場的啟發

此長文提供了一條中文市場少見的專業論述路徑:不自稱「心靈療癒」,而是以「行為改變顧問」的定位進入企業——先狀態(IS)、再思考歷程(IP)、最後行為(EB)。Molden 的客戶見證(英鎊計價的企業訓練成果)也顯示:**B2B 定位比 B2C 工作坊定位在英語系世界有更高的單價天花板**,這與 06 教練應用指南的市場定價地圖可以互相對照——台灣 NLP 教練若定位「企業溝通/領袖狀態顧問」,定價可對標國際顧問行情而非台灣身心工作坊行情。

**使用建議**:在設計自己的商業定位文件(07 技能發展路線)時,可引用 Mercedes 模型作為「為什麼傳統訓練無效」的說服框架;在與企業客戶提案時,此模型可直接轉化為簡報架構(狀態→思考→行為)。
