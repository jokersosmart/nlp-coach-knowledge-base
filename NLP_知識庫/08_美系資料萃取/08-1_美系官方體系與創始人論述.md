# 08-1 美系官方體系與創始人論述(繁中譯本)

**萃取日期**:2026-08-17 | 本文件整合 Bandler 官方網站、NLP 官方定義頁、New Code NLP 官網與 NLPU 官網的公開內容,以繁體中文完整譯述。

## 一、Bandler 官方對 NLP 的正式定義

來源:neurolinguisticprogramming.com(全文重點譯述)

> 「神經語言程式學(NLP)是**主觀經驗結構的研究,以及可從中計算出的事物**,其前提信念是:所有行為都有結構。」

Bandler 一系的論述強調:模型來自對 Satir、Erickson、Perls 三人的語言與行為模式的**模仿(modeling)**。因為這些模型是形式化的(formal),所以可以**預測與計算**——甚至可從中推導出這三位大師自己未曾使用過的新模式。原文明確指出:

> 「NLP 不是診斷工具。它只能被應用,因此只能以體驗式(installation,『安裝』而非『教導』)的方式教學。」
>
> 「技巧會自己過時。NLP 不以技巧為基礎,而是以**態度、模型與技能**為基礎——它們允許不斷生成更有效、更快的新技巧。」

原文還有一條對照台灣市場極具啟發性的哲學:

> 「學習不分等級。一旦某人學會了某件事的底層模式,內容就自然延伸……名字與證書只是名字與證書,不是材料也不是知識。」

**教練應用**:向案主介紹時,可用這段原文作為「NLP 是什麼」的最高版本答案;同時用它提醒自己在教學中優先建立「態度與模型」,而非堆疊技巧。

## 四、New Code NLP 完整介紹(Grinder 一系)

來源:newcodenlp.org(全文重點譯述)

**Grinder 系與 Bandler 系的根本分歧**。Grinder 自 1988 年起與 Carmen Bostic St Clair 共同發展 New Code NLP,並透過著作《Whispering in the Wind》(2001)正式與 Classic Code(1974–1978)區分。核心差異在操作層級:

| 維度 | Classic Code | New Code |
| --- | --- | --- |
| 操作層級 | 行為層級(output) | 狀態與意圖層級(input) |
| 無意識角色 | 被動 | 明確賦予選擇權(狀態、資源、新行為) |
| 新行為要求 | 由執行師設計 | 必須滿足原行為的正向意圖 |
| 自我應用 | 不保證 | **必備能力**(Self-application) |

Grinder 觀察到 Classic Code 訓練出來的執行師「對案主極有效,卻無法對自己應用 NLP」,因此 New Code 要求呈現者必須與自我應用一致(congruent)。三大 New Code 核心概念:

1. **Inductive Learning(歸納式學習)**:Bostic St Clair 引入,核心是「無意識吸收模式」,如同兒童學母語;口訣是「A pattern discovered is a pattern owned(被發現的模式即被擁有的模式)」。
2. **New Code Games**:透過遊戲產生「最佳化狀態(high performance states)」,行為成為改變過程的自然產物;遊戲基礎為舞蹈、球類、節奏、詩歌、音樂。
3. **Disciplined Know-Nothing State(自律的無知狀態)**:遊戲激活的「內容自由、最佳化狀態」;配合 **SOS signals(Spontaneously Occurring Signals)** 與無意識/內在團隊直接溝通。

過渡期文獻:Grinder 與 DeLozier 的《Turtles All the Way Down》(1987)研討會逐字稿。

**教練應用**:New Code 的「自我應用」要求是對照台灣課程最直接的品質指標——一個連自己都無法應用的 NLP 訓練師,其教學深度需要打折扣。
