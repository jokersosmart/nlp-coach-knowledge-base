# 技巧卡 05-4:換框法與框架層次

**模組**:G 框架與信念|**優先度**:★★★☆☆(第 6 週練)|**證據等級**:B

---

> **證據警示(v2.1)**:換框與認知心理學的「認知重評(cognitive reappraisal)」在操作層面高度共鳴,而認知重評有大量實證支持——因此換框可視為「有科學共鳴的 NLP 技術」(B 級)。可安心用於自我與他人練習,但「所有行為必有正向意圖」是內建假設(D 級),不必爭論真假。

---

## 一、原理

同一件事換一個框架,情緒與行為就不同。NLP 認為「問題」與「資源」的差別往往不在事實本身,而在**看事實的框架**。台灣知名 NLP 導師張忘形的示範:演講前緊張,可以換框為「我會緊張,代表我很在乎,我很興奮能跟這麼多人分享!」把焦慮重新解釋為興奮,行為表現往往就此改變。

換框分兩大類:**內容換框(Reframing Content)**——同一件事換一個意義(「緊張 = 在乎」);**語境換框(Context Reframing)**——同樣的行為,在另一個情境下反而有價值(「固執」換框為「堅持原則,在需要守護底線時是美德」)。更系統化的版本是 **Six-Step Reframing(六步換框)**,用來處理習慣與內在衝突:找出行為 → 建立與「 responsible part(負責的那個部分)」的溝通 → 辨認**正向意圖** → 尋找能滿足同一正向意圖的三個新行為 → 由負責的部分選定新行為 → 生態檢查(新行為不會在其他地方造成問題)。

## 二、步驟腳本:六步換框(自我版)

1. 選定一個想改變的行為(例:「我總是拖延」)。
2. 靜下來,詢問內在:「這個行為想保護我、替我做的是什麼?」(不帶批判,讓答案自然浮現)。
3. 辨認**正向意圖**(拖延常是為了「保護我免於失敗的打擊」或「保留選擇空間」)。
4. 邀請內在創意:「除了拖延,還有哪三種方式可以同時達成保護我與完成事情?」列出至少三種。
5. 讓負責的那個部分選定一個它最願意嘗試的新方式。
6. 生態檢查:「這個新方式,會讓我生活的其他部分付出什麼代價?」若有,回到步驟 4。

## 三、框架層次(Frame Levels)

Goodman 筆記(模組 17)與後續發展者補充的「層次語言」,用來決定會談中提問的高度:

| 層次 | 提問範例 | 功能 |
| --- | --- | --- |
| 環境 | 在哪裡發生?和誰?什麼時候? | 定位事件 |
| 行為 | 你做了什麼? | 描述行動 |
| 能力 | 你是怎麼做到的?用到什麼能力? | 引出資源 |
| 信念/價值 | 這對你為什麼重要?你相信什麼? | 觸動動機 |
| 身分 | 你是誰?這反映你是什么样的人? | 深化認同 |
| 精神/系統 | 你為誰、為更大的什麼而做? | 超越自我 |

**上切(Chunk Up)**問「這是什麼的例子/這更大的目的是什麼」;**下切(Chunk Down)**問「具體是哪一部分/舉一個例子」;**旁切(Lateral Chunk)**問「這像什麼」。語言模式大師 Tony Robbins 的演講即頻繁使用數字化框架(「3 件事」「6 個人類需求」)讓內容好記——這是上切框架的現場示範。

## 四、常見問題

- **Q:換框會不會變成「毒雞湯」,否定別人的痛苦?** A:會,如果用在別人身上而沒有親合感。換框是**邀請**,不是**駁斥**。正確時機:親合感建立後,對方表達困擾時輕聲問「如果換一個角度……你會怎麼看?」而不是直接說「你想開一點」。
- **Q:正向意圖找不出來怎麼辦?** A:用假設句降低門檻:「假設這個行為有一個好的理由,你猜會是什麼?」——大腦對假設的防衛較低。
- **Q:六步換框和「心理諮商」的界線在哪?** A:針對「習慣、拖延、內在矛盾」可用;針對「創傷、憂鬱、焦慮症」不適用,應轉介專業心理師。這是本知識庫反覆強調的倫理線。

## 五、練習方法(第 6 週)

每天把一件煩心事做一次內容換框;每週一次語境換框;每週一次完整六步換框(自我版);進階對練:與夥伴交換困擾事件,用提問引導對方自己換框(注意:引導換框,不要幫對方換框——**換框的答案必須由案主說出才有效**)。

## 六、教練應用

換框是 NLP 教練會談中使用率最高的技巧,但專業姿勢來自杜華心苑心理師學員的提醒:「**緊緊跟隨**」——不強加執行師的意念,而是跟隨當事者的思維前進;執行師的意念只在當事者需要再深入的幫忙時才派上用場。換框的正確時機:案主卡在舊框架裡、明顯有未被看見的角度時,用提問(而非宣告)帶出第二個框架。
