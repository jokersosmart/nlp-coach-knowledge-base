## 萃取 1:New Code NLP 官網(newcodenlp.org)——New Code NLP 完整介紹(已截取全文重點)

**來源**:https://www.newcodenlp.org/(已存 /home/ubuntu/upload/www.newcodenlp.org__1786947400305.md)

重點:
- New Code NLP 由 John Grinder 與 Carmen Bostic St Clair 自 1988 年共同創建,與 Classic Code(Grinder+Bandler,1974–1978)明確區分
- 核心差異:操作在**狀態與意圖層級**(input)而非行為層級(output);無意識被明確賦予選擇關鍵元素(狀態、資源、新行為)的責任;新行為必須滿足原行為的**正向意圖**
- New Code NLP Games(受 Roger Tabb 啟發):透過遊戲產生「最佳化狀態」(high performance states)→ 行為作為改變過程的自然產物
- **Inductive Learning(歸納式學習)**:Bostic St Clair 引入,核心是「無意識吸收模式」,如同兒童學母語;口訣「A pattern discovered is a pattern owned」(被發現的模式即被擁有的模式)
- **Self-application(自我應用)**:New Code 必備能力——Grinder 觀察到 Classic Code 訓練的執行師「對案主極有效,卻無法對自己應用 NLP」,因此設計「呈現者必須與自我應用一致(congruent)」的模式
- Disciplined Know-Nothing State(自律的無知狀態):New Code 遊戲激活的「內容自由、最佳化狀態」
- Spontaneously Occurring Signals(SOS signals):與無意識/內在團隊溝通的直接訊號
- 著作:Whispering in the Wind (2001)——New Code 與 Classic 的正式區分;Turtles All the Way Down (1987)——Grinder 與 Deloizier 的研討會逐字稿(過渡期)
- Bostic St Clair 的模式基於舞蹈、球類遊戲、節奏、詩歌、音樂

## 萃取 4:neurolinguisticprogramming.com —— Bandler 官方對 NLP 的正式定義(全文重點)

**來源**:https://www.neurolinguisticprogramming.com/

- **官方定義**:**NLP 是「主觀經驗結構的研究,以及可從中計算出的事物」**,前提信念是「所有行為都有結構」
- 模型來自模仿 Satir、Erickson、Perls 的語言與行為模式;因為模型是「形式化的(formal)」,所以可以**預測與計算**——可從中推導出這三人自己未曾使用過的新模式
- **NLP 不是診斷工具**;只能被應用,因此只能以**體驗式**教學(installation,「安裝」而非「教」)
- 「技巧會過時,所以 NLP 不以技巧為基礎,而是以**態度、模型與技能**為基礎,讓新技巧不斷被生成」——這是 Bandler 系與教材派的根本差異
- **無預修要求哲學**:「學習不分等級。一旦學會某件事的底層模式,內容就自然延伸」(識字後 5 頁與 200 頁的書沒差)——對照台灣課程的「階級化認證體系」
- 「名字與證書只是名字與證書,不是材料也不是知識」

## 萃取 8:PMC 2024 精神醫學期刊文獻《Neurolinguistic programming: Old wine in new glass》(Kattimani & Abhijita, Indian Journal of Psychiatry, 2024)

**來源**:https://pmc.ncbi.nlm.nih.gov/articles/PMC11293289/

重點(全文萃取):
- 文獻定義 NLP 為「心理學與溝通領域,聚焦神經歷程、語言與行為模式的關係」;**沒有統一定義**;核心概念 Preferred Representational System(PRS,偏好表象系統)「沒有可靠驗證的評估方法」
- Heap(1988)審查 63 項研究:「透過眼動與行為辨識 PRS 的假設缺乏充分證據」;predicate matching(語言與對方感官述詞一致)的療效也未被證實
- **Sturt 等人(2012)系統性回顧**(回應英國 NHS 審查):10 項研究(5 RCT + 5 前後測)結論——「**沒有足夠證據推薦 NLP 用於任何健康狀況**(研究用途除外)」
- 相反面:**Zaharia 等人(2015)meta-analysis**(NLP  practitioners 自辦):12 項前瞻性研究,NLPt 總體標準化平均差異 0.54(CI 0.20–0.88)——但異質性極高(病況、族群、結果量尺、次數、技術類型都不同)
- 關鍵漏洞:支持性研究「未釐清 PRS 是否隨情境變化」;目前**無任何心理學教科書提及 NLP**
- NLP 技術與 CBT/ACT 有共同點(框架、換框、錨定類似制約、信念控制類似認知重評),若有以 CBT 為對照組的 RCT,證據等級才能建立
- 恐懼症案例的 NLP 解釋:恐懼是快速 Pavlovian 制約;錨的「collapse(錨定合併)」= 同時激活正反錨、先撤負錨
- 商業描述:NLP 是「significant industry」,大量資金在英國流動;組織主要鎖定醫療與心理系學生;美加澳印課程漸流行但從未進入心理學課程

**教練視角的誠實應用**:向案主說明「NLP 的技巧元素(換框、錨定、正向意圖)與 CBT/ACT 有理論共鳴,但 NLP 本身缺乏大型 RCT 證據」——這是 06 倫理心法的強化版。

## 萃取 11:NLPU 100 官方執行師課程手冊《Background and Principles of NLP》(免費 PDF 全文萃取)

**來源**:https://www.nlpu.com/FoundationSample/NLPU100Doc/NLPU%20100%20Background%20of%20NLP-s.pdf(Dilts & DeLozier 官方課程書冊,頁 5–7)

**完整定義(NLPU 官方版)**:NLP 是 1975 年由 Bandler & Grinder 創立的「**行為模型 + 一組明確的技能與技術**」,定義為「**主觀經驗結構的研究**」,研究腦(neuro)、語言(linguistic)與身體互動產生的模式(programming)。NLP 提供三層:
1. **認識論(Epistemology)**——知識與價值的體系
2. **方法論(Methodology)**——應用知識與價值的流程與程序
3. **技術(Technology)**——協助應用知識與價值的工具

**歷史線**:The Structure of Magic I&II(1975/76,模仿 Perls 與 Satir)→ Patterns of the Hypnotic Techniques of Milton Erickson I&II(1975/76)→ 正式命名 NLP。核心團隊貢獻對照表:
| 人物 | 貢獻 |
| --- | --- |
| Leslie Cameron-Bandler | Meta Programs、Imperative Self(1985/86) |
| Judith DeLozier & Grinder | 知覺位置 Perceptual Positions、**NLP New Coding**(1987) |
| Robert Dilts | 認知策略與信念系統(1983/90/91)、邏輯層次、S.C.O.R.E. |
| David Gordon | 次感元與隱喻(1978) |
| Stephen Gilligan | 催眠(1991) |
| Steve & Connirae Andreas | 核心轉化 Core Transformation、螺旋等 |
| Tad James | 時間線療法 Time Line Therapy |

**兩條根本前提**(手冊原文):1) **地圖不是領土**(我們只能知道自己的感知地圖;卓越來自「選擇最多」的地圖);2) **生命與心智是系統性歷程**(自我組織、seek 穩態 homeostasis)。「卓越來自擁有許多選擇;智慧來自擁有多種視角。」

**改變的基本公式(手冊原文)**:**現狀 + 適當資源 → 期望狀態**(Present State + Appropriate Resources → Desired State)——所有 NLP 技術的功能都是「豐富/添加有效行為的三個特性之一」。

**原始核心技術清單(手冊列舉)**:後設模式、表象系統優位、Accessing Cues、感官述詞、同步與帶領、錨定、換框、改變個人歷史、V-K 解離、狀態管理。

## 萃取 12:《NLP in Business》(David Molden,Positive Health, 2009,長文全文)

**來源**:https://www.positivehealth.com/article/nlp/neuro-linguistic-programming-nlp-in-business(商業 NLP 教練的重要原始素材)

作者 David Molden 是企業訓練出身的懷疑論者→擁護者。關鍵萃取:

**Mercedes 模型(IS × IP × EB)**:任何行為(EB, External Behavior)都伴隨內在狀態(IS, Internal State)與內在思考歷程(IP, Internal Processing)。除非新行為能以相同的 IS 與 IP 生成,否則任何理論/模型/程序都無法改變行為——「要行為改變,先從狀態開始,再進入思考歷程」。對照傳統訓練「只給行為」所以無效。

**信心建構案例**:信心是 IS+IP 的函數;失去信心=自我對話介入(「我會搞砸」「他們很難搞」)→立即衝擊情緒狀態→先用 NLP 處理狀態,才用新語音新詞語。

**習慣=IS+IP+EB**:只改變 EB(行為層)幾乎不可能;時間管理訓練失敗的實例→引入 NLP 的 **Time Coding + Time Lines**:個人對時間的感知是多年習慣性 IP/IS/EB 的產物,建立新的心理時間線來重掌時間運用。

**EQ 論述**:NLP 有成套增加 EQ 的技術;高階 NLP 訓練師「先用 NLP 創造適當的 IP 與 IS,再轉移技能到職場」。
