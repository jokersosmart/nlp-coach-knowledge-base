# 10-4 部署與使用指南

**撰寫日期**:2026 年 8 月 17 日 | 說明如何在本知識庫與 Manus 中啟用 NLP 教練 Agent。

## 一、三種使用層級

| 層級 | 做法 | 適合場景 |
| --- | --- | --- |
| L1 直接對話 | 在 Manus 開新任務,說「啟動我的 NLP 教練 Agent」並要求讀取 10_教練Agent 資料夾與 09 證據地圖 | 立刻可用,零設定 |
| L2 提示詞貼入 | 把 10-2 第五節的「Agent 提示詞模板」貼入 Manus 系統提示詞或自建聊天工具 | 固定角色、更穩定 |
| L3 技能包裝載 | 將本知識庫發展為 Manus Skill(依 07-1 的 Skills 化路線),裝載後輸入「我圖卡」式的觸發語即可啟動 | 長期制度化 |

## 二、L1 快速啟動語

> 「請讀取我的 NLP 知識庫中 10_教練Agent/10-1 設計規格、10-2 會談腳本引擎、10-3 提問庫與 09_詳細檢視報告/09-1 證據地圖,按照 10-1 的角色定義與 10-2 的提示詞模板,作為我的 NLP 教練 Agent 與我對話。先問我想要練習、學習還是演練會談。」

## 三、建議的首次對話流程

第一次啟動時依序進行:先用「學習」模式問一個技巧(如心錨),驗證 Agent 的回答是否附證據等級;再用「演練」模式讓 Agent 當案主演一次 45 分鐘會談;最後在「自我練習」模式做當日練習並請 Agent 寫會談紀錄(10-2 第四節模板)。
