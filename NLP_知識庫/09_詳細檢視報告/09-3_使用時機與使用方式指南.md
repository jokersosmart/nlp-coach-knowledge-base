# 09-3 使用時機與使用方式指南

**撰寫日期**:2026 年 8 月 17 日 | **目的**:回答三個問題——這套知識庫(含技能包與教練 Agent)什麼時候該用、什麼時候不該用、怎麼用才對。基於 09-1 證據地圖、05 技巧卡與 10 教練 Agent 的交叉分析。

## 一、先理解一個原則:「時機」由兩個維度決定

知識庫內容的使用時機不是由「今天心情」決定,而是由**對象**(對誰用)+ **議題嚴重度**(處理什麼)兩個維度交叉決定。下表是全知識庫的第一張導航圖:

| 議題嚴重度 | 對自己在 | 對家人朋友在 | 對案主/學員在 |
| --- | --- | --- | --- |
| **日常困擾**:緊張、拖延、目標模糊、溝通不順 | 全套可用(05 技巧卡 + Agent 引導) | 輕量可用:親合感、換框、提問 | 45 分鐘會談流程(10-2) |
| **中度情緒**:持續焦慮、壓力、習慣難改 | 可用 B/D 級,A 級最穩;C 級當練習 | 可用狀態管理與目標設定 | 可用,但明示「這是練習非治療」 |
| **臨床議題**:創傷、恐慌症、憂鬱症、自傷 | **停止使用 NLP 框架,立即轉介** | 溫和陪伴,轉介專業 | **倫理紅線:停止會談,轉介** |

這張表的實用意義是:**NLP 技巧的真正使用時機是「日常與中度的自我管理與溝通」,不是「心理疾病的處理」。** 知識庫中 A、B、D 級的內容(錨定、換框、後設模式提問、狀態管理、目標設定)完全落在安全區;C 級(次感元、時間線、恐懼快速療法)只能以「練習體驗」的心態使用;E 級(眼動讀心)則應從一切實際操作中移除,只保留鑑別教學用途。

## 二、逐技巧的使用時機地圖

以下把九張技巧卡映射到具體生活情境,每項標注等級、建議頻率與用法:

| 技巧 | 最佳使用時機 | 不建議的使用時機 | 建議頻率 |
| --- | --- | --- | --- |
| 05-1 表象系統與察覺 | 初次見面、跨部門溝通前;日常培養觀察力 | 宣稱能「讀懂對方的思維模式」時 | 每日 5 分鐘觀察練習 |
| 05-2 親合感與知覺位置 | 衝突發生後、說服/談判前、道歉時 | 對方已察覺並反感同步動作時 | 衝突後必用;日常隨緣 |
| 05-3 心錨 | 上場前(演講、面試、比賽)、狀態低落需自我喚起時 | 期望它「治癒」焦慮症時 | 建立後每日複習一次 |
| 05-4 換框法 | 卡關思考時、對自己或他人下負面判斷時、想理解一個「壞習慣」時 | 用來迴避真實問題、粉飾傷害時 | 每週 2–3 次換框練習 |
| 05-5 後設模式 | 聽到模糊概括語句時(「我老是…」「他們都…」);幫助他人釐清需求時 | 連續追問像審問時(每輪一題) | 隨對話自然出現 |
| 05-6 次感元 | 自我練習:調整焦慮畫面的距離/大小/色彩,比較感受 | 向案主宣稱確定的療效時 | 練習心態,自行驗證 |
| 05-7 正向意圖與目標 | 設定任何目標時;對自己有負面評價時問「正向意圖是什麼」 | 用來為他人的傷害性行為辯護時 | 每次設定目標必用 |
| 05-8 時間線 | 想重新建立與過去的關係感(非治療)、規劃未來視覺化 | 宣稱能「移除/修改」過去的創傷記憶時 | 輕度議題可用;創傷禁用 |
| 05-9 解離與恐懼快速 | **僅限輕度緊張**(上台、考試);先自練再對人 | 恐慌症、創傷、 diagnosed 疾病 | 自練為主,對人極謹慎 |

## 三、依「人生階段與身份」的使用建議

**階段一:您現在(學習者,想自我成長)**。使用時機是「每天的真實生活事件」——早上通勤練感官述詞觀察、工作遇到挫折練六步換框、設定目標時走良好形成六問、重要場合前裝心錨。知識庫的 05 技巧卡按 05-0 的 12 週路徑使用,**每週一個技巧,每天一個小練習**。搭配 Agent 的模式是「自我練習模式」:每天結束時對 Agent 說「我今天做了 XX 練習」,請它引導下一步。

**階段二:練習到會對話(準教練,有搭檔或練習對象)**。使用時機是「雙週一次的 45 分鐘練習會談」——用 10-2 會談腳本引擎當流程,10-3 提問庫當彈藥。搭配 Agent 的模式是「教練演練模式」:讓 Agent 當模擬案主演練,或當觀察者對您的會談逐段給回饋。這個階段的核心產出是「會談的穩定手感」。

**階段三:開始接案(收費教練)**。使用時機是「正式會談」與「會談之間」:會談中用 10-2 的 45 分鐘流程與轉介模板;會談間用 10-2 的會談紀錄模板與 Agent 做案例複盤。這個階段的關鍵轉折是倫理自律——對案主永遠只使用 A/B/D 級框架,明示 C 級工具「未驗證、僅練習」,絕不碰臨床議題(轉介)。

**階段的判斷標準(何時升級)**:階段一到二,以「能獨立帶完一次完整 45 分鐘流程、案主(或練習搭檔)回饋正向」為升級線;階段二到三,以「累積 20 次以上練習會談、能誠實說明證據等級、轉介案例零失誤」為升級線(06-1 與 07-1 有更細的里程碑)。

## 五、教練 Agent 的三種使用情境與操作範例

**情境一:每日自我練習(最常用)。** 啟動語:「啟動我的 NLP 教練 Agent,進入自我練習模式,我想練今天的心錨練習。」Agent 會按腳本逐步引導、逐問推進、結束時給回饋並請您寫下 48 小時內的第一步。**建議時機:每天晚上 10–15 分鐘**,與 05-0 練習路徑同步。

**情境二:會談前演練與會談後複盤。** 啟動語:「進入教練演練模式,你當模擬案主,情境是『想換工作但不敢辭職』,按 10-2 的 45 分鐘流程帶我。」演練後再問:「以 06 的倫理界線檢查我剛剛的會談,哪裡越線、哪裡做得好。」**建議時機:每兩週一次正式演練 + 每次真案會談後 10 分鐘複盤。**

**情境三:知識查證與證據諮詢。** 啟動語:「有個技巧我想對朋友介紹——恐懼快速療法,它可信嗎?用 09-1 的證據等級告訴我。」Agent 會給出等級、來源與「怎麼誠實地向對方介紹」的話術。**建議時機:每當您想對他人使用任何 NLP 技巧之前**(這是知識庫設計的「使用前查證」安全閥)。

## 六、三個「不要」(紅線時機)

第一,**不要在對方不知情的情況下對他人「操作」技巧**。NLP 技巧在對話中自然流出的效果遠好於刻意的「操作感」;尤其換框與提問,一旦被感覺在「被術」,親合感會瞬間崩塌。第二,**不要在情緒風暴中對別人用技巧**。對方處於高度情緒時,先接納與陪伴(純粹接收),技巧性操作等情緒降溫後再進行——這是 01 杜華心苑心得與 10-2 開場原則的共同結論。第三,**不要對臨床議題越界**。創傷、恐慌症、憂鬱症、自傷意念出現時,唯一正確的操作是 10-2 的轉介模板——這不是能力不足,而是專業教練的標誌。

## 七、今日就能開始的三個行動

1. **今晚**:對 Agent 說啟動語,做第一次「自我練習模式」對話(10 分鐘)。
2. **明天**:在通勤或工作間做一次「感官述詞觀察」(05-1,5 分鐘)。
3. **本週**:挑一個您正卡住的小目標,用 05-7 的良好形成六問走完一遍,並把答案寫進會談紀錄模板。

完成這三步後,您就已經把知識庫從「讀懂」推進到「用起來」——這正是 00 導論中「安裝優於教導」的第一次驗證。
