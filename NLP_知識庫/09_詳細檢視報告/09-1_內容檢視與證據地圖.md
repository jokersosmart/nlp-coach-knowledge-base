## 一、檢視方法與證據強度分級

本次檢視對知識庫每一項主張進行三重核對:回溯原始來源網址、對照英語系學界研究文獻、檢查內部一致性(同一知識庫內不同來源之間是否矛盾)。每項主張依證據強度分為五級:

| 等級 | 標示 | 意義 | 對應行動 |
| --- | --- | --- | --- |
| A | **已證實** | 有獨立、方法學良好的實證研究支持 | 可安心用於教練與教學 |
| B | **理論共鳴** | 與有證據基礎的理論(CBT/ACT/古典制約/自我調節)共鳴,但 NLP 本身未經獨立驗證 | 可用,但應以「成分」而非「NLP 原創」定位 |
| C | **高引用未驗證** | 被行業廣泛引用,但實證研究反覆未能複製 | 可作為練習框架,不可宣稱科學效力 |
| D | **定義性/方法論** | 非科學命題,是 NLP 的內在假設或操作規則 | 作為思考工具使用,不必爭論真假 |
| E | **已被否證** | 實證研究明確否定其可檢驗主張 | 從教練論述中移除,僅作為歷史與鑑別教學 |

## 三、重大矛盾點分析

### 矛盾一:PRS/眼動假說——高頻引用卻被否證(等級 E)

這是知識庫中最重要的矛盾。中文市場與多數入門教材仍以「眼動辨識表象系統」「配對感官述詞」為核心賣點,但英文學界有三重獨立否證:Heap(1988)審查 63 項研究 [2]、Sturt(2012)系統性回顧 [1]、Witkowski(2010)三十年回顧 [3],一致的結論是「透過眼動與行為辨識 PRS 的假說缺乏充分證據」。05-1 技巧卡中「察覺眼動」的練習功能(培養觀察力、注意對方的思維模式變化)仍然有訓練價值——**作為練習工具(D 級)可用,作為「讀心術」(E 級)不可用**。

### 矛盾二:Bandler 系「反認證」哲學 vs 整個產業的認證體系(等級 D,自相矛盾)

neurolinguisticprogramming.com 原文主張「學習不分等級,名字與證書只是名字與證書」[11],但同一 Bandler 擁有的 Society of NLP 卻頒發 Practitioner/Master Practitioner/Trainer 證書,英國 ANLP 與國際 INLPTA 也以三級文憑體系運作(Sturt 原文指出 [1]),NHS 三年內還花費 £802,468 採購 NLP 訓練 [1]。**產業依賴認證經濟,創始人否定認證——**對您未來做教練的定位啟示:不必為證書付溢價,但可利用證書作為市場信號(誠實地)。

### 矛盾三:Classic Code vs New Code 的操作論分歧(等級 D)

同一個「NLP」名稱下存在兩套不兼容的操作論:Bandler 系在行為層級操作( Classic Code),Grinder 系在狀態與意圖層級操作且要求自我應用(New Code)[10]。Grinder 的原話:Classic Code 訓練出的執行師「對案主有效,卻無法對自己應用」。這解釋了為何市場上大量 NLP 從業者自己狀態混亂——**New Code 的「自我應用一致性」是對照任何教練課程品質的第一指標**。

### 矛盾四:支持面與批評面證據的對讀(等級 C)

Zaharia et al.(2015)報告 SMD 0.54 的中效度 [12],但 Kattimani 指出其異質性極高且研究由從業者自辦 [4];Sturt 指出「支持性論述大多來自行業內部資料」[1]。**讀法**:Zaharia 不是「NLP 有效」的證明,而是「NLP 成分值得進一步研究」的信號——與 Passmore & Rowson「成分可用、整體包裝未證實」的立場一致 [7]。

### 矛盾五:縮寫歧義造成的證據混淆(重要新發現)

本次核對發現 JMIR(2024)一篇標題含「NLP models」的 meta-analysis(Villarreal-Zegarra et al.,SMD 0.819)實為**AI 自然語言處理**的介入研究,而非神經語言程式學 [13]。搜尋引擎與部分中文轉述會把兩者混淆。您的知識庫以 08-3 區隔已正確,此處作為檢索時的自我提醒。

## 四、哪些是「核心重點」

綜合兩派創始人原文與百科,以下主張構成 NLP 不可約簡的核心(D 級方法論),無論證據爭議如何都值得完整掌握:

1. **地圖不是領土**(NLPU [8])——所有換框與知覺位置的哲學底座
2. **現狀 + 適當資源 → 期望狀態**——所有技術的共同公式 [8]
3. **正向意圖**(所有行為的背面都有一個試圖滿足的需要)——六步換框與道德中立立場的來源
4. **卓越來自選擇最多、智慧來自視角最多**——多選項思維是 NLP 對「問題」的唯一解法
5. **安裝(installation)優於教導**——體驗式學習法,解釋為何課堂練習重於知識講授
6. **自我應用一致性**(New Code [10])——從業者自己的狀態是第一教具

## 五、結論

知識庫的萃取本身完整且忠實(01–04 區塊忠實保留了來源的聲音),但其中承載的部分主張在證據上屬 C–E 級。本報告建議的立場與 06 教練指南一致:**把 NLP 當作「練習工具與方法論」而非「科學治療體系」使用**,並把教練產品定位在 B 級成分區(目標、提問、狀態、換框的認知共鳴版本)。
