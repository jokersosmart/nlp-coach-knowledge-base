# 進階技巧卡:ICF 職能 CC6–CC7(積極聆聽、喚起覺察)× NLP 工具

> **卡片定位**:進階教練職能系列第三卡,對應 ICF 職能 C 類(有效溝通)。這是會談的「引擎室」——聆聽收集素材,提問引發轉變。NLP 在這裡的工具密度最高,但也要最謹慎(語言模式可被濫用,米爾頓模式尤須證據誠實)。

**證據等級**:ICF 職能 = D 級;後設模式 = B 級(提問澄清研究支持其溝通效果,不保證認知改變)、換框 = B 級、知覺位置 = C/D 級、米爾頓模式 = B/C 級(類比的說服效果有研究,催眠式語言的深層效果未被證實)、隱喻 = B 級(隱喻干預有中等證據)。

## CC6 積極聆聽(Listens Actively)

ICF 定義:關注客戶**在說什麼、不在說什麼**,充分理解客戶在其系統背景下的溝通內容,支持客戶的自我表達。

| ICF 子能力 | NLP 工具 | 具體操作 |
| --- | --- | --- |
| 注意「話中還有更多」並追問 | 05-5 後設模式(刪除、扭曲、簡化) | 案主說「大家都反對我」→ 後設模式:「**誰**具體反對?在哪件事上?」(還原被刪除的主語與情境) |
| 注意情緒、能量、非語言暗示 | 05-1 VAK 察覺 + B.A.G.E.L. | 案主語速突然放慢、視線上移、身體後仰 → 這些訊號先於語言,標記下來,稍後邀請展開 |
| 整合用詞、語調、身體語言 | 05-2 親合感建立中的三通道收聽 | 同時聽「詞彙的表象系統(看/聽/感覺)」「語調的升降(能量)」「身體的開合(狀態)」 |
| 識別主題與模式 | 05-8 時間線觀察(非操作) | 聽案主敘事時標記時態語言:「我**總是**這樣」(泛化的時間模式)、「**上次**也是」(重複序列)——這些是行為策略的語言痕跡,會談後複盤用 |
| 反映與總結確保理解 | 10-3 提問庫的反映式提問 | 「讓我確認:你剛才說的是……對嗎?」——反映 + 確認是 CC6 的核心動作 |

**聆聽的三層框架**(結合後設模式與 B.A.G.E.L.):第一層聽**內容**(他在說什麼事件);第二層聽**語言結構**(後設模式捕捉刪除/扭曲/簡化——這些缺口就是提問的入口);第三層聽**身體與能量**(五通道訊號——這些訊號告訴你有什麼還沒被說出來)。成熟教練的聆聽是同時三層運作。

## CC7 喚起覺察(Evokes Awareness)

ICF 定義:透過強有力發問、沉默、隱喻或類比等工具,引發客戶的洞見與學習。

| ICF 子能力 | NLP 工具 | 具體操作 |
| --- | --- | --- |
| 針對思考方式/價值/信念提問 | 05-5 後設模式提問庫 | 「『一定不行』這個想法,是**誰**告訴你的一定不行?」(信念來源探詢) |
| 支持客戶**重塑觀點** | 05-4 換框法(內容換框 + 脈絡換框) | 案主:「我太衝動了」→ 脈絡換框:「衝動在什麼情境下反而有用?」→ 內容換框:「衝動的正面意圖是什麼?(可能是快速行動的動力)」 |
| 幫助識別影響現在與未來的行為/思考/情緒模式 | 05-8 時間線技術 | 用時間線回顧:「站在一年後回頭看,這次卡關教會了你什麼?」(以未來視角重構現在,避免過度解離的安全版用法) |
| 邀請分享當下體驗 | 05-6 次感元(描述層面) | 「你說想到這件事會不舒服——那現在,那個不舒服的畫面在你內在是什麼樣子?大小?遠近?顏色?」(描述即覺察) |
| 用**隱喻/類比**引發洞見 | 05-4 換框 + 米爾頓模式的隱喻結構 | 案主卡關:「想像你是一個被鎖住的房間,門沒鎖,你只是還沒試轉門把」(類比換框) |
| 不帶附加地分享觀察 | 05-2 知覺位置(第一位置的中立表達) | 「我注意到你講到這段時語速變快了——那是什麼?」(只陳述觀察,不附加解讀,讓案主自己命名) |
| 透過**沉默**引發覺察 | 10-2 腳本的沉默規範 | 強有力提問後 7–10 秒不補話;沉默是提問的一部分,不是冷場 |
| 依據客戶體驗選最有效方式 | 05-0 技巧總目錄的情境對應表 | 案主是視覺型 → 用畫面語言提問;案主在關係議題 → 知覺位置;案主在恐懼議題 → 次感元描述層面 |

**米爾頓模式的倫理使用說明**(重要,證據誠實):米爾頓模式(模糊語言、允許式結構、嵌入暗示)是 Erickson 催眠語言的教練化應用,B 級(部分研究支持其說服與放鬆效果)與 C 級(深層效果未驗證)並存。在教練脈絡的**正確用法**:創造開放性(「你可以慢慢來」)、允許式提問(「你可能會發現⋯⋯」)、隱喻故事。在教練脈絡的**禁止用法**:隱蔽地植入暗示改變案主決定(那是操控,違反 ICF CC1 的子能力 2.01 案主自主,也違反本技能倫理硬規則)。

## 練習方法

1. **後設模式聽力訓練**(每日 10 分鐘):選一段訪談影片,只聽「刪除/扭曲/簡化」的語言缺口,標記數量。目標:每分鐘標記 3 個以上缺口。
2. **換框對練**(每週一次):練習夥伴丟一個限制句(「我口才不好」「我撐不起這個專案」),你在 30 秒內給出脈絡換框 + 內容換框各一個。
3. **觀察式陳述練習**(每日):對身邊的人只陳述觀察不附加解讀,每天 3 次(「你今天笑聲比較大聲」「你走路速度比平常快」)。

## 常見問題

**Q:換框會不會變成「合理化客戶的痛苦」?** 可能,這是換框被濫用的典型。操作原則:換框前**先確認**「我是否充分聽見了你的痛苦」(CC4 先於 CC7);換框後**確認**「這個新視角對你有幫助嗎?還是你覺得被敷衍了?」。換框失敗就回到聆聽。

**Q:米爾頓模式與後設模式方向相反,該怎麼用?** 後設模式=讓語言**更精確**(澄清、具體化),用於收集素材與合約;米爾頓模式=讓語言**更開放**(暗示、允許),用於放鬆與激發內在搜尋。會談節奏:前半用後設模式(收集),中段可切換米爾頓(探索),結尾回到後設模式(落實行動)。
