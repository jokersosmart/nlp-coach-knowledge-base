# 進階技巧卡:ICF 職能 CC4–CC5(信任安全感、臨在)× NLP 工具

> **卡片定位**:進階教練職能系列第二卡,對應 ICF 職能 B 類(共建關係)的 CC4 與 C 類的 CC5。這是會談「場域」的基礎——沒有信任與臨在,後續所有 NLP 技巧都不會發揮作用。

**證據等級**:ICF 職能 = D 級(認證定義);NLP 工具:親合感 = B 級(行為模仿研究支持模仿,但不支持讀心)、察覺練習 = A/B 級、狀態管理 = A 級(古典制約延伸)、New Code 一致性 = B 級。

## CC4 培養信任和安全感(Cultivates Trust and Safety)

ICF 定義:與客戶合作創造安全的、支持性的環境,允許客戶自由分享,保持相互尊重與信任的關係。

| ICF 子能力 | NLP 工具 | 具體操作 |
| --- | --- | --- |
| 了解客戶背景(身分/環境/經歷/價值/信念) | 05-2 親合感建立 | 會談開場 5–10 分鐘:語言節奏配合(語速、音量)、姿態鏡像(自然不做作)、呼吸同步 |
| 尊重客戶的觀點、風格、語言 | 05-1 表象系統察覺 + 語言配合 | 客戶說「我看不到方向」→ 用視覺語言回應(「我們來讓它更清楚」);客戶說「這讓我很沉重」→ 用感覺語言回應 |
| 表達支持、同理、關心 | 05-2 知覺位置第二位置 | 聽對方敘事時進入第二位置(用他的眼睛看、用他的身體感受),回應才有真實同理 |
| 以開放透明展現**脆弱**建立信任 | 05-4 換框(正向意圖) | 教練適度自我揭露「我也有類似卡住的經驗」時,先對自己換框:揭露的目的是服務客戶,不是安慰自己 |

**B.A.G.E.L. 察覺四通道(08-1 New Code 補充)**:傳統 NLP 只有 VAK,Grinder 的 New Code 擴展為 **B.A.G.E.L.**——**B**ody(身體)、**A**ccess(可及性/呼吸)、**G**estures(手勢)、**E**ye(眼睛)、**L**anguage(語言)。CC4 要求的「尊重客戶的語言」在 B.A.G.E.L. 框架下可操作化為:會談前 3 分鐘,依次掃描案主的五個通道——姿勢開闊或縮小?呼吸深淺?手勢頻率?視線方向模式?語言偏好詞彙(V/A/K)?——建立完整的親合感基線。

**重要證據提醒(09-1)**:模仿(matching/mirroring)的研究支持集中在「行為模仿增加好感度」(B 級),**不代表**模仿能讀心或保證親合(那是被否證的 E 級眼動讀心的延伸)。使用方式:作為表達尊重的工具,而非操控工具。05-2 技巧卡的操作界線同樣適用此處——對方察覺到被模仿會破壞信任,自然度優先於完整度。

## CC5 保持臨在(Maintains Presence)

ICF 定義:全然地、有覺察地與客戶同在,展現開放、靈活、腳踏實地、自信的教練風格。2025 版維持定義不變。

| ICF 子能力 | NLP 工具 | 具體操作 |
| --- | --- | --- |
| 專注、觀察、同理、回應 | 05-1 純粹接收(5 分鐘練習) | 會談中 80% 時間在接收、20% 在說話;觀察案主的 VAK 述詞與非語言訊號而不急著介入 |
| 展現好奇心 | 05-5 後設模式提問 | 用後設模式把案主的模糊語言具體化:「你說的『更好』具體是什麼樣子?」 |
| 管理自己的情緒,與客戶同在 | 05-3 資源錨定(自我應用) | 會談前啟動自信/平靜錨;會談中被案主情緒牽動時,暗中觸發錨定回到狀態 |
| 對強烈情緒展現信心 | 05-6 次感元(觀察層面) | 案主哭泣或憤怒時,用次感元觀察「這段情緒在他內在的畫面/聲音/感受」,保持穩定不逃跑 |
| 舒適地待在未知空間 | 00 前提假設 + 新 Code 一致性 | 「地圖不是領土」——教練也不需要全知;坦然說「我也不知道,但我們一起看看」 |
| 創造沉默/暫停/反思空間 | 10-2 腳本 + 米爾頓模式 | 問完強有力問題後**停 7–10 秒不補話**;沉默是米爾頓模式的「允許式」結構——給案主內在搜尋的空間 |

**「臨在」的 NLP 狀態管理操作腳本**(會談前 10 分鐘,可直接練習):

1. **呼吸同步**(1 分鐘):吸氣 4 秒、吐氣 6 秒,五輪,降低生理喚起。
2. **資源錨啟動**(1 分鐘):觸發練習過的成功/平靜錨定(05-3),讓身體記得那種狀態。
3. **B.A.G.E.L. 自我掃描**(2 分鐘):自己的姿勢、呼吸、手勢、視線、語言準備好了嗎?
4. **意圖設定**(1 分鐘):「今天我要全然與這個人同在,方向由他的目標決定。」
5. **開場進入會談**,前 5 分鐘只做觀察與親合感建立,不急著「做事」。

## 練習方法

1. **每週一次「臨在對話」**:找練習夥伴,10 分鐘對話中只做三件事——觀察五通道、模仿語言模式、允許沉默。不問問題、不給建議。這是 CC4+CC5 的純度練習。
2. **會談錄音複盤**:聽自己的會談錄音,標記「說話比例」「平均回應等待秒數」「是否打斷案主」。目標:說話比例 < 25%、等待 > 7 秒。
3. **錨定演練**(每日):會談前狀態管理腳本做成固定流程,21 天後成為自動化。

## 常見問題

**Q:模仿對方會不會顯得刻意?** 會,如果做全套。B.A.G.E.L. 的建議是只選 1–2 個通道做輕微配合(例如只配合語速與呼吸),自然度遠比完整度重要;被察覺的模仿破壞信任,這比不做更糟。

**Q:案主情緒很強烈時,我該用技巧還是純陪伴?** 依 09-3 的時機指南:情緒風暴中先純粹陪伴(符合 CC5 的「與客戶同在」),等案主自己平靜、提出探索意願後,才進入技巧工作。這個順序本身就是 CC4 安全感的體現。
