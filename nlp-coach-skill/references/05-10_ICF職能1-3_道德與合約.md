# 進階技巧卡:ICF 職能 CC1–CC3(道德、心態、合約)× NLP 工具

> **卡片定位**:這是「進階教練職能系列」第一卡,將 ICF 國際教練聯盟八項核心職能(2021 版,2025 年微調)與 NLP 技巧卡對應結合。ICF 職能是**認證標準(D 級:定義性)**,NLP 成分是**工具庫(依各自證據等級)**。會談前必須同時滿足兩者。

**證據等級**:ICF 職能本身 = D 級(認證定義,無證據爭議);對應的 NLP 工具依 09-1 證據地圖。

## CC1 展現道德規範(Demonstrates Ethical Practice)

ICF 定義:理解並持續應用教練道德準則與標準,包括正直誠信、對客戶身分/環境/經歷/價值/信念敏感、尊重語言、保密、**區分教練與諮詢/心理治療**,以及**適時轉介**(子能力 1.07)。2025 版強調遵守 ICF 核心價值。

與本知識庫的對應是直接的:09-1 證據地圖與 10-2 轉介模板就是 CC1 的操作化。執行的三個具體動作:

| ICF 要求 | NLP 知識庫對應工具 | 操作要點 |
| --- | --- | --- |
| 區分教練/治療 | 09-3 紅線區 | 創傷、恐慌症、重度憂鬱、自傷意念 → 不用任何技巧,直接轉介 |
| 適時轉介(1.07) | 10-2 轉介模板 | 使用逐字稿:「我聽到這件事已經超出教練能處理的範圍,我希望你聯繫 1925 安心專線/身心科醫師」 |
| 對客戶背景敏感 | 05-2 親合感 + B.A.G.E.L. | 先察覺身分、文化、語言脈絡再開始 |

**教練應用提醒**:NLP 社群歷史上最大的倫理爭議(宣稱能「治療」心理疾病)正是違反 CC1 的子能力 1.06。使用 NLP 技巧時若說「這個技巧可以治好你的焦慮症」,同時違反 CC1 與本技能倫理硬規則。正確的說法是「這個技巧可以作為狀態管理的練習」。

## CC2 體現教練心態(Embodies a Coaching Mindset)

ICF 定義:開放、好奇、靈活、以客戶為中心。**2025 修訂重點**:定義新增「持續投入個人與專業學習發展、必要時與教練督導或導師合作」;新增子能力 2.09(培養自己/客戶/過程的開放好奇)與 2.10(覺察自己的思想行為對客戶的影響);2.07 升級為「會談前、中、後維持情緒/身體/心理安康」。

這與 NLP 的**自我應用一致性原則**(Bandler/Grinder 強調教練自己的狀態)高度共振,對應的 NLP 工具:

| ICF 子能力 | NLP 工具 | 具體做法 |
| --- | --- | --- |
| 2.01 客戶對自己的選擇負責 | 05-7 正向意圖 + 前提假設「每個人都是自己人生的駕駛」 | 不替客戶做決定;提問引導而非指導 |
| 2.02–2.03 持續學習與反思 | 10-1 的會談複盤模式 | 每次會談後寫三行:這次哪裡好、哪裡可改進、下次試什麼 |
| 2.04 覺察偏見/情境/文化影響 | 05-2 知覺位置第三位置 | 會談後站在第三方視角審視自己的判斷是否被偏見帶走 |
| 2.05 運用自我覺察與直覺 | 05-1 純粹接收 + B.A.G.E.L. | 會談中持續掃描自己的身體感受與腦中畫面,那是直覺的訊號 |
| 2.06 調節情緒 | 05-3 自我心錨(資源錨) | 會談前啟動自信錨定;會談中情緒波動時重新觸發 |
| 2.07 維持情緒/身體/心理安康 | 05-3 狀態管理 + 新 Code 自我一致性 | 會談前 10 分鐘:呼吸 → 啟動資源錨 → 確認身心狀態 |
| 2.10 覺察自己對客戶的影響 | 05-2 知覺位置 1↔2 切換 | 會談中定期自問:「我剛才那句話,是在我的立場還是他的立場說的?」 |

## CC3 建立和維持合約(Establishes and Maintains Agreements)

ICF 定義:與客戶合作建立關係/流程/計畫/目標的清晰協議,含整體合約與每次會談合約。2025 新增子能力 3.12「必要時重訪合約」;3.01 改為「說明自己的教練哲學並定義什麼是/不是什麼」。

合約在 NLP 框架中對應 **T.O.T.E. 的測試(Test)環節與良好形成目標的成功標準**(子能力 3.08):

| ICF 子能力 | NLP 工具 | 會談腳本 |
| --- | --- | --- |
| 3.01 說明教練是什麼 | 10-2 開場宣告(第 3 分鐘) | 「教練不是給建議,而是陪你用自己的資源找到答案」——這句本身就是 CC3 的聲明 |
| 3.06–3.07 確認本次想完成什麼 | 10-2 會談合約段 + 10-3 良好形成六問 | 「今天的會談,你希望結束時帶走什麼?」→ 收斂成一句可衡量的目標句 |
| 3.08 成功衡量標準 | 05-7 T.O.T.E. 測試設計 | 「怎麼知道我們做到了?你會看到什麼、聽到什麼、感受到什麼?」——用感官述詞(VAK)讓標準可檢測 |
| 3.09 管理時間與焦點 | 10-2 流程計時 + 05-0 練習路徑 | 開場時說明:「我們有 45 分鐘,前 5 分鐘定目標,中間 30 探索,最後 10 整合與行動」 |
| 3.12 重訪合約 | 10-2 中場檢核 | 會談中段問:「我們現在的討論方向,還符合你一開始說的目標嗎?」 |
| 3.11 尊重地結束關係 | 10-2 結尾段 | 總結學習 → 確認行動 → 感謝 → 明確後續(續約或結束) |

**教練應用提醒**:ICF 認證考核(ACC/PCC/MCC)以「職能示範」評分,不以時數論。NLP 技巧在這個區塊的作用不是「改變客戶」,而是**讓合約清晰可執行**——這是 NLP 工具在專業教練領域最安全的用途,因為它服務的是流程,不是改變客戶內在。

## 練習方法

1. **會談前自我檢核清單**(3 分鐘):CC2 心態準備(啟動資源錨)→ CC3 合約設計(本次目標一句話 + 成功標準)→ CC1 界線確認(案主議題是否落在紅線區)。
2. **會談後複盤**(5 分鐘):用 2.10 的視角問「我今天的哪些話或狀態影響了客戶?」,並記錄一個下次改進點。
3. **督導替代練習**:若暫無督導,每兩週用 10-1 的複盤模式自我督導一次,並閱讀 ICF 職能行為描述比對自己的錄音或筆記。

## 常見問題

**Q:我還沒考 ICF 認證,可以用這些職能嗎?** 可以。職能描述是公開標準,練習對照不會違規;但對外不得宣稱「ICF 認證教練」,那是 CC1 的正直誠信要求。

**Q:NLP 的「快速療法」與 CC1 的治療界線衝突嗎?** 衝突時以 CC1 為準。恐懼快速療法(05-9)只能以「練習體驗」對一般恐懼(上台、面試)使用;對創傷性記憶絕對禁止——這正是 ICF 子能力 1.06 與 1.07 的意義。
