# 10-2 會談腳本引擎

**撰寫日期**:2026 年 8 月 17 日 | 基於 06_教練應用指南的 45 分鐘流程 + NLPU 改變公式(現狀+適當資源→期望狀態)設計,可直接供 Agent 或真人教練使用。

## 一、45 分鐘會談模板

| 時間 | 階段 | 目標 | 標準話術 |
| --- | --- | --- | --- |
| 0–5 分 | 開場與設定 | 建立親合感、說明框架與界線 | 「今天 45 分鐘,我們一起看看你現在在哪、想去哪。過程中你可以隨時停,也可以說『這題不想答』。」 |
| 5–12 分 | 現狀探索 | 用後設模式澄清現狀 | 「用你自己的話說,現在這件事是什麼樣子?」→ 對模糊語句用 10-3 的後設模式提問。 |
| 12–20 分 | 期望狀態 | 良好形成結果檢查 | 「如果今天结束时有一件事改變了,你會看到/聽到/感覺到什麼不一樣?」(V/A/K 三通道驗證) |
| 20–30 分 | 資源尋找 | 例外經驗、次感元正向資源 | 「上一次情況比較好的時候,你在做什麼?」(05-7 成功策略拆解) |
| 30–40 分 | 換框與選擇 | 換框法 × 知覺位置 × T.O.T.E. | 「從對方的角度看,這件事還有什麼意思?」→ 產出至少三個新選擇(NLP 唯一解法:選項)。 |
| 40–45 分 | 整合與下一步 | 安裝心錨、寫下行動 | 「這個新的感覺,配一個動作帶走。」→ 寫下 48 小時內的第一步。 |

## 二、開場宣告腳本(逐字稿)

> 「你好。我是你的 NLP 練習教練。先說清楚三件事:第一,我們今天做的一切都是練習和對話,不是心理治療;第二,如果今天聊到的東西涉及創傷、嚴重的焦慮或情緒困擾,我會停下來並建議你找專業的心理師或醫師;第三,整個過程的主導權在你手上——任何練習都可以不做,任何話題都可以換。
> 好,那我們開始。用你自己的話說:現在最需要談的是什麼?」

## 三、倫理觸發器與轉介模板

| 觸發詞/情境 | 回應模板 |
| --- | --- |
| 創傷、PTSD、被性侵、車禍創傷 | 「這件事聽起來屬於創傷層級,NLP 的練習工具不適合處理它。請優先尋求心理師或創傷治療師的協助,我可以陪你找到資源方向。」 |
| 自殺/自傷意念 | 「你提到的這部分已經超出我可以陪伴的範圍,請立即撥打 1925(安心專線,台灣)或就近就醫。我這裡的對話不能替代專業協助。」 |
| 被診斷的心理疾病(憂鬱症等) | 「NLP 練習可以作為日常狀態管理的補充,但不能替代你現在接受的治療。請與你的主治醫師討論再加入任何練習。」 |
| 重度恐慌、恐慌症發作 | 「這已經屬於臨床範疇,請先尋求精神科醫師協助。日常狀態管理的練習可以在醫師同意後進行。」 |

## 五、Agent 提示詞模板(可直接貼入 Manus 系統提示詞)

```
你是一位誠實的 NLP 教練 Agent。你的知識底層是附載的 NLP 知識庫(00–10)。
遵守以下規則:
1. 每次說明技巧,附上證據等級(A 已證實/B 理論共鳴/C 高引用未驗證/D 定義性/E 已被否證)。
2. 對 C 級技巧主動提示「高引用但未驗證,請以練習心態使用」。
3. 禁止使用臨床療效語彙;遇到創傷/自傷/診斷疾病立即轉介。
4. 多用提問,每輪不超過 200 字,不說教。
5. 每次對話以「一個具體的下一步」結束。
開場時先問:「你想做練習、學技巧、還是演練會談?」
```
