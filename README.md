# NLP 教練知識庫(Neuro-Linguistic Programming)

**作者:Joker** | 版本:v2.1(2026 年 8 月 17 日)

本儲存庫是一套完整的神經語言程式學(NLP,非 AI 自然語言處理)知識體系,跨台灣與美國來源萃取公開資料,涵蓋上課心得、讀書筆記、演講逐字稿、免費教材、證據審查、教練 Agent 與技能包,目標是支持三個發展階段:**自我練習 → 成為教練 → 發展為可複用的技能包**。

## 目錄結構

```
├── NLP_介紹/                      ← 入門導讀(是什麼、怎麼學、自學資源、免費萃取資料來源)
├── NLP_知識庫/                    ← 主體(61 個檔案)
│   ├── 00_導論與知識地圖/          ← 是什麼、九大模組、12 條前提假設
│   ├── 01_萃取資料_上課心得/       ← 杜華心苑工作坊實錄、流動瓶子課後實作筆記
│   ├── 02_萃取資料_讀書筆記與部落格/ ← 方格子書評、持證訓練師教學文章
│   ├── 03_萃取資料_演講逐字稿/     ← Tony Robbins TED 逐字稿、NPR 訪談
│   ├── 04_萃取資料_免費講義與教材/  ← Goodman 160 頁執行師筆記、美系訓練手冊 PDF
│   ├── 05_NLP技巧大全/             ← 九張技巧卡(原理→腳本→常見問題→練習→證據警示)
│   ├── 06_教練應用指南/            ← 從學習者到教練之路、倫理界線
│   ├── 07_技能發展路線/            ← 12 週練習系統、可販售產品設計
│   ├── 08_美系資料萃取/            ← Bandler 原文、兩派體系、SNLPU 百科、研究文獻、商業應用
```

## 使用建議

1. **第一次**:讀 `NLP_介紹/神經語言程式學_完整介紹.md` 建立全貌,再讀 `NLP_知識庫/00_導論與知識地圖/`
2. **練習技巧**:按 `05_NLP技巧大全/05-0_技巧總目錄與練習路徑.md` 的 12 週路徑,每週一卡
3. **想知道可信度**:先讀 `09_詳細檢視報告/09-1_內容檢視與證據地圖.md` 的證據分級表(24 項主張,A 已證實 → E 已被否證)
4. **想知道什麼時候用什麼**:讀 `09_詳細檢視報告/09-3_使用時機與使用方式指南.md`
5. **開始會談**:讀 `10_教練Agent/` 並按部署指南裝載 Agent

## 重要說明

- 本知識庫以**證據誠實**為核心:NLP 被學界歸為缺乏充分實證的領域,故全部內容依證據等級標注,A/B/D 級(錨定原理、換框、目標設定、前提假設)可安心練習,C 級(次感元、時間線)僅練習心態,E 級(眼動讀心)已從操作移除。
- 本知識庫僅供個人學習使用,不構成心理治療或醫療建議;臨床議題一律轉介專業人員。
- 所有萃取內容來自公開網路資源,各檔案內標註原始連結。
